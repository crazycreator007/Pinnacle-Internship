# 📅 Calendar & Reminder App

A Python-based desktop application that combines a monthly calendar with a reminder management system. The application provides an interactive graphical interface for viewing dates and managing reminders efficiently.

## ✨ Features

- 📆 Display monthly calendars
- ◀️ Navigate to previous months
- ▶️ Navigate to upcoming months
- 🖱️ Select individual dates
- ➕ Add reminders for selected dates
- 👀 View reminders for a selected date
- ✏️ Edit existing reminders
- 🗑️ Delete reminders
- 🔔 Visual reminder indicator on calendar dates
- 💾 Store reminders permanently using JSON
- 🎨 Modern dark-themed graphical user interface

## 🛠️ Technologies Used

- **Python 3**
- **Tkinter** – Graphical User Interface
- **JSON** – Persistent reminder storage
- **Python Calendar Module** – Monthly calendar generation
